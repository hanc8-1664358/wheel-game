# 幸运转盘

一个可以自定义选项的网页转盘，适合聚会抽奖、随机分组，或帮你做个小决定。电脑和手机都可以玩。

## 怎么玩

1. 点击转盘中央的「开始」。也可以用鼠标拖动转盘，或在手机上滑动转盘。
2. 在「自定义选项」中添加或删除格子，修改名称、颜色和权重，最多支持 40 个格子。
3. 选择「等概率」或「按权重」。等概率模式下，每个选项被抽中的机会相同。按权重模式下，权重越高，被抽中的机会越大。
4. 转盘停下后会显示结果。想继续抽，点击「再转一次」。

## 保存与分享配置

转盘配置和最近 30 条抽取记录会自动保存在当前浏览器中。点击「导出」可下载 JSON 配置文件，其他人可以通过「导入」加载同一套选项和概率设置。

## 本地运行

下载 [lucky_spin.html](./lucky_spin.html)，用浏览器打开即可游玩。游戏由单个 HTML 文件组成，无需安装依赖或启动服务器。

## 手机端

手机上采用转盘优先的单页布局，点击「自定义转盘」展开设置。选项以卡片展示，可直接编辑名称、权重和颜色；点击中央按钮或在转盘上滑动均可抽签。页面支持横竖屏、安全区留白及浏览器缩放。导入、导出和历史记录功能保留。

## 浏览器验证

安装 Node.js 22 或更新版本及 Chromium 后，在仓库目录运行：

```sh
node tests/mobile-smoke.mjs
```

测试会启动临时本地服务器和独立的无头浏览器，检查多种手机尺寸、横屏与桌面布局、设置展开、触控尺寸、滑动抽签、手势取消及配置和历史保存。可通过 `CHROMIUM_PATH` 指定 Chromium 可执行文件；运行环境需允许本地套接字及浏览器进程。测试不修改游戏数据或依赖文件。iOS Safari 的系统文件选择、下载和虚拟键盘表现仍建议用真机检查。
